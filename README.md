## Desafio técnico para vaga de desenvolvedor fullstack para a Agrotis

Projeto de resposta ao teste da Agrotis para vaga de Desenvolvedor Fullstack.
 
- Inicialização do projeto:
	- Clone o repositório
	- Abra em uma IDE de sua preferencia (Eclipse, Intelij)
	- Copie o arquivo de referencia `src\main\resources\application.properties.example` para `src\main\resources\application.properties`
	- Adicione as suas chaves dentro do arquivo copiado (como requisitado no arquivo)
	- Verifique se o banco que você configurou está rodando
	- Rode o projeto pela sua IDE ou pela linha de comando se preferir com o maven `.\mvnw.cmd spring-boot:run`
